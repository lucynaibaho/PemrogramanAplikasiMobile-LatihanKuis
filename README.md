# PemrogramanAplikasiMobile-LatihanKuis

Aplikasi katalog buku Flutter untuk latihan kuis mobile.

## Fitur

- Login demo dengan username dan password.
- Katalog buku dalam grid yang dapat dipilih.
- Halaman detail berisi informasi buku dan rating.
- Tombol keluar untuk kembali ke halaman login.

## Menjalankan aplikasi

Pastikan Flutter SDK sudah terpasang, lalu jalankan:

```bash
flutter pub get
flutter run
```
